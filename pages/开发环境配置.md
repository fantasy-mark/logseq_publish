	- ### 解决离线包无法下载案例（ominiparser）
	- **项目涉及一些非官方whl包，配置IT仓库后，依旧有大量whl包无法下载**
	  ```shell
	  # requirements.txt
	  torch
	  torchvision
	  pyautogui==0.9.54
	  ...
	  ```
		- collapsed:: true
		  1. **注释**个别不能下载的包，特别的 `torch` 和 `torchvision`（需要CUDA版本）也注释掉
			- ```shell
			   pip download --platform manylinux2014_x86_64 --python-version 3.12 --only-binary=:all: -r .\requirements.txt --dest ./offline-packages
			   ```
		- collapsed:: true
		  2. 通过`nvidia-smi`查看CUDA版本，并选择合适`CUDA`版本`torch`安装，如下则选择 https://download.pytorch.org/whl/cu126 仓库进行下载
			- 查看 `torch` 和 `torchvision` 两者需要配套版本（https://pytorch.org/get-started/previous-versions）
			- ```bash
			   root@gpuserver190:~# nvidia-smi
			   Thu Jan 15 14:02:53 2026       
			   +-----------------------------------------------------------------------------------------+
			   | NVIDIA-SMI 560.35.03              Driver Version: 560.35.03      CUDA Version: 12.6     |
			   ...
			   # 尝试安装，可能需要安装依赖，优先到 https://download.pytorch.org/whl/cu126 查找
			   pip install torch-2.6.0+cu126-cp312-cp312-manylinux_2_28_x86_64.whl torchvision-0.21.0+cu126-cp312-cp312-linux_x86_64.whl
			   ```
		- collapsed:: true
		  3. 尝试安装，处理安装失败的包，直接到官网（https://pypi.org/）或使用以下命令下载 ，可能需要手动
			- `--only-binary=<格式控制>`：使用二进制包。可接受的值包括` :all:`（使用所有二进制包）、`:none:`（清空集合）或一个或多个用逗号分隔的包名。
			- `--prefer-binary`：优先下载二进制包，即使源包更新。
			- ```shell
			   # 尝试安装，递归处理无法安装的包
			   pip install --no-index --find-links offline-packages -r .\requirements.txt
			   # 优先下载二进制包，无法下载则下载源码包
			   pip download --platform manylinux2014_x86_64 --python-version 3.12  --only-binary=:all: pyautogui==0.9.54 --dest ./offline-packages
			   pip download --platform manylinux2014_x86_64 --python-version 3.12 --prefer-binary pyautogui==0.9.54 --dest ./offline-packages --no-deps
			   ```

- ## docker/podman
  collapsed:: true
	- ### login/logout repo
	  
	  ```shell
	  podman login xxxx.com
	  docker login xxxx.com
	  ```
	- ### docker-外网
	  
	  ```shell
	  sudo mkdir -p /etc/systemd/system/docker.service.d
	  sudo tee /etc/systemd/system/docker.service.d/http-proxy.conf << EOF
	  [Service]
	  Environment="HTTP_PROXY=http://User:Password@IP:PORT"
	  Environment="HTTPS_PROXY=http://User:Password@IP:PORT"
	  Environment="NO_PROXY=localhost,127.0.0.1,.local"
	  EOF
	  ```
	  
	  ```json
	  sudo tee /etc/docker/daemon.json << EOF
	  {
	  "registry-mirrors": [
	    "https://docker.m.daocloud.io",
	    "https://docker.imgdb.de",
	    "https://docker-0.unsee.tech",
	    "https://docker.hlmirror.com",
	    "https://docker.1ms.run",
	    "https://func.ink",
	    "https://lispy.org"
	  ]
	  }
	  EOF
	  ```
	  
	  ```shell
	  # 重新加载 systemd 配置
	  sudo systemctl daemon-reload
	  
	  # 重启 Docker 服务
	  sudo systemctl restart docker
	  
	  # 验证配置是否生效
	  sudo systemctl show --property=Environment docker
	  ```
